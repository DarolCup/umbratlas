# Umbratlas 0.3.1 · Lavender Night

Обновлённое оформление для Fedora KDE:

- Чернильный фон, лавандовые акценты, спокойные сине-фиолетовые поверхности.
- Карточки графа с мягким градиентом, подсветкой при наведении и цветными индикаторами состояния.
- Точечная сетка, тонкие связи и полоска прогресса маршрута.
- Новое приветствие, увеличенные отступы, скруглённая панель урока и единое оформление прокрутки.

Данные, карты и прогресс сохраняются.

Установка или обновление пользовательской версии:

```bash
curl -fsSL https://raw.githubusercontent.com/DarolCup/umbratlas/main/install.sh | bash
```

Для установки через RPM скачай `umbratlas-0.3.1-1.noarch.rpm` и выполни:

```bash
sudo dnf install ./umbratlas-0.3.1-1.noarch.rpm
```
