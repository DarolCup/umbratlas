Umbratlas v0.2.0 добавляет подключение GhostModel и других OpenAI-совместимых провайдеров.

- Готовый профиль GhostModel с адресом https://ghostmodel.cc/v1.
- Свой HTTPS Base URL и выбор протокола Chat Completions или Responses API.
- Загрузка каталога моделей и ручной ввод ID.
- Отдельные ключи на время сессии для каждого адреса.
- Поиск статей и видео в браузере для моделей без автоматического веб-поиска.

Установить или обновить на Fedora KDE можно одной командой.

```bash
curl -fsSL https://raw.githubusercontent.com/DarolCup/umbratlas/v0.2.0/install.sh | bash
```

В архиве исходники и установщик. Контрольная сумма в `SHA256SUMS`.
