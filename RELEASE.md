# Umbratlas 0.3.0 · Fedora KDE

Настольный ИИ-преподаватель с интерактивными картами обучения.

- Настройки, диагностика, самопроверка, повторение и чат с учителем открываются внутри единственного главного окна.
- Диагностика по одному вопросу с навигацией назад/вперёд, ограничением в 17 вопросов и сохранением ответов.
- Основные и необязательные темы; обязательный маршрут не зависит от дополнительных веток. Масштабирование карты: Ctrl + колесо мыши.
- Подробная теория, уточняющие вопросы учителю, практика, проверка ИИ и шпаргалки.
- Поиск источников через API с web_search; статьи, поиск и видео открываются во встроенном Qt WebEngine.
- Черновики практики сохраняются в SQLite. После перерыва от семи дней появляется вопрос на повторение и возможность получить план возвращения от ИИ.
- Готовый noarch RPM, архив исходников и SHA256SUMS. Старые базы сохраняются и обновляются автоматически.

## Установка

Скачай `umbratlas-0.3.0-1.noarch.rpm` из вложений и выполни:

```bash
sudo dnf install ./umbratlas-0.3.0-1.noarch.rpm
```

Открой **Umbratlas** в меню KDE. Для новых карт подключи свой API-ключ в настройках. Без ключа доступны две демонстрационные карты, практика и повторение.

Веб-поиск требует поддержки `web_search` выбранным провайдером. Воспроизведение видео зависит от сайта и установленных мультимедийных кодеков. Платные API-вызовы в автоматических тестах заменены проверяемыми ответами.
