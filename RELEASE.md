Первая настольная версия Umbratlas для Fedora KDE.

- Карты обучения по произвольной цели. ИИ уточняет опыт, формирует темы и связывает их зависимостями.
- Поиск статей и видео по запросу. Найденные ссылки сохраняются в карточке темы.
- Практика с критериями, самопроверкой и текстовой обратной связью от ИИ.
- Шпаргалки, повторение с интервалами и продолжение с сохранённого места.
- Два примера без API-ключа, C++ и готовка.

Установка одной командой.

```bash
curl -fsSL https://raw.githubusercontent.com/DarolCup/umbratlas/v0.1.0/install.sh | bash
```

Для генерации и поиска нужен свой ключ OpenAI API. В архиве исходники и установщик. SHA-256 архива в `SHA256SUMS`.
